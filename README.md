# Bassey Birthday Experience

A cinematic, interactive birthday tribute website created in celebration of **Bassey Uduak**, Managing Director of Plural Media & Technologies Limited.

Designed as a digital expression of appreciation, this experience brings together elegant visuals, personal photography, animated storytelling and background music to celebrate an exceptional leader.

**Birthday Celebration:** December 2, 2026

---

## About the Project

The Bassey Birthday Experience is a custom-designed digital birthday tribute built to celebrate leadership, inspiration and impact.

The website takes visitors through a visual birthday experience, beginning with an elegant welcome screen and continuing into a personalised celebration featuring photographs, appreciation messages and a cinematic closing tribute.

## Features

- **Cinematic Welcome Screen:** An elegant introduction with an interactive reveal button.
- **Animated Birthday Experience:** Smooth entrance animations and scroll-triggered transitions.
- **Personalised Portrait Section:** Dedicated birthday message and photography.
- **Interactive Photo Gallery:** Clickable photographs with an image lightbox.
- **Tribute Messages:** Appreciation messages celebrating leadership and impact.
- **Cinematic Birthday Finale:** A closing birthday message from the Plural Media team.
- **Background Music:** Soft instrumental music with play and pause controls.
- **Animated Sound Wave:** Visual sound-wave animation while music is playing.
- **Responsive Design:** Designed to provide an enjoyable experience across screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP (GreenSock Animation Platform)
- GSAP ScrollTrigger
- Google Fonts

## Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/femi2c-gif/bassey-birthday-experience.git
```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` using the Live Server extension.

Alternatively, open `index.html` directly in your browser.

## Music and Media Assets

The project uses locally stored images, the Plural Media logo and a background instrumental.

All required assets are located inside the `assets` folder.
